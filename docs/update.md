# Обновление

1. Сделайте резервную копию базы.
2. Остановите бота и API: `docker compose stop bot api`.
3. Получите новую версию кода. Секреты в `.env` не перезаписывайте.
4. `docker compose up -d --build`.
5. Если появилась новая ревизия Alembic: `docker compose run --rm api alembic upgrade head`.
6. Текущая первая ревизия создаёт таблицы из моделей. На уже инициализированной базе `upgrade` безопасен: `create_all` не удаляет существующие таблицы.
7. Проверьте `/health`, вход в панель и что бот отвечает на `/start`.
8. Прогоните `python -m pytest` на машине разработчика до выкладки.

Несовместимое изменение схемы оформляйте новой ревизией Alembic, а не правкой `0001_initial`.
