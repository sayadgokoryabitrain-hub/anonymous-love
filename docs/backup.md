# Резервное копирование

Финансовый журнал и профили живут в PostgreSQL. Копируйте базу до обновлений и по расписанию.

Windows, из каталога проекта:

```powershell
.\scripts\backup.ps1
```

Linux:

```sh
sh scripts/backup.sh
```

Файл появляется в `backups/anonymous-love-ДАТА.sql`. Каталог `backups` не коммитится. Храните копии вне сервера.

Копировать также `.env` в защищённое место: без секретов восстановленная база не свяжется с ботом и администраторами нельзя будет выпустить новые токены тем же ключом. Файлы фотографий сервис на диске не хранит: в базе остаётся временный `file_id` Telegram и хеш.

Проверка копии: поднимите пустой Postgres и выполните `psql -U love -d anonymous_love -f backups/файл.sql`.
