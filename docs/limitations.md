# Известные ограничения

- Подбор первой версии соединяет только парня и девушку. Оба должны попадать в возрастное окно друг друга. Совпадений нет — бот так и пишет, выдуманную пару не подставляет.
- Возраст 18+ подтверждается заявлением при регистрации и, отдельно, процедурой верификации. Селфи с кодом не доказывает пол и возраст.
- Анонимность не абсолютна. Пользователь сам отвечает за текст, который отправляет, и за то, что копирует за пределы бота. Telegram ID другим людям не показывается.
- Закрытые до верификации действия перекрыты во всех обработчиках бота: фото, видео, голос, контакты, геолокация, username и ссылки. Обычный текст, стикеры и реакции до проверки разрешены. Случайную ссылку, спрятанную обходом, который фильтр не распознал, Telegram API отличить надёжно нельзя.
- Ссылки с схемами `javascript`, `data`, `file`, сокращателями и известными трекерами IP блокируются и после верификации.
- Username раскрывается только если обе стороны подтверждены, у пользователя он есть и он разрешил показ.
- LoveCoins нельзя купить как рейтинг доверия и нельзя вывести. Доверие считается из проверки, возраста анкеты и подтверждённых нарушений.
- VIP даёт фильтры, лимиты и небольшой приоритет при равенстве баллов. Он не обходит возраст, блокировки, верификацию и жалобы. Фото и жалобы не продаются.
- Реферальные 100 монет начисляются один раз после завершения регистрации и подтверждения профиля приглашённого, не за сам переход по ссылке.
- Mini App доверяет только подписанному `initData`. Без HTTPS Telegram его не откроет. Бот от этого не зависит.
- История сообщений хранится ограниченно и чистится фоновой задачей. Для жалобы сохраняется фрагмент конкретного сообщения.
- Тестовая оплата невозможна в production. Успешный платёж в коде не имитируется.
